# cljd2dart

A small **ClojureDart → Dart source transpiler written in ClojureDart**.

It reads a `.cljd` file, translates a practical ClojureDart subset to readable
Dart source, and appends a small runtime so the generated file is standalone.
It is a source-to-source translator for learning, scripts, and small tools — it
is **not** a replacement for the real ClojureDart compiler, and it does not
support the Flutter UI DSL.

## Quick start

```sh
cd tools/cljd2dart

# Rebuild if needed, transpile, and write examples/hello.dart
./cljd2dart examples/hello.cljd -o examples/hello.dart

dart run examples/hello.dart
```

Without `-o`, the input extension is replaced with `.dart`:

```sh
./cljd2dart examples/features.cljd   # writes examples/features.dart
```

Read from stdin and write to stdout:

```sh
cat examples/hello.cljd | ./cljd2dart - --stdout
```

### Flutter example

`flutter_counter/` is a basic Flutter counter app whose `lib/main.dart` is
generated by cljd2dart from `flutter_counter/cljd/main.cljd`. Because the
transpiler does not support the Flutter DSL or Dart named arguments, the app
uses a small positional widget bridge in `flutter_counter/lib/ui.dart`.

```sh
cd flutter_counter
./generate.sh
flutter run -d linux
```

See `flutter_counter/README.md` for details.

## CLI

```
cljd2dart <input.cljd> [-o output.dart]
cljd2dart <input.cljd> --stdout
cljd2dart - --stdout

Options:
  -o, --output <file>   Write Dart to <file>
      --stdout          Write Dart to standard output
  -h, --help            Show help
  -v, --version         Show the version
```

`-` means "read ClojureDart source from stdin". The default output path is the
input path with `.cljd` (or `.clj`) replaced by `.dart`.

## Requirements

- Clojure CLI with the dependencies in `deps.edn`
  (`tensegritics/clojuredart` tag `0.9.20261002`)
- Dart SDK 3.x
- Python 3 only when regenerating the embedded runtime

## Building

```sh
clojure -M:cljd compile
```

The generated transpiler entry point is
`lib/cljd-out/cljd2dart/main.dart`, launched by `bin/cljd2dart.dart`.
The `./cljd2dart` wrapper recompiles automatically when a `.cljd` source is
newer than the generated Dart.

## Tests

```sh
./scripts/test.sh
```

Each `examples/*.cljd` file is transpiled to a temporary directory, analyzed
with `dart analyze`, executed, and its stdout is compared with the matching
`examples/*.expected` file. The script also checks `--help`, `--version`, and
stdin/stdout operation.

## Supported subset

### Namespaces and definitions

- `ns` with `:require` of `cljd.core`, `cljd.string`, `cljd.set`, and Dart
  library imports such as `["dart:math" :as math]`
- `:as` and `:refer` for Dart library imports
- `def`, `defonce`, `defn`, `defn-` (docstrings and metadata are accepted)
- private definitions are emitted with a leading `_`

### Expressions

- literals: numbers, strings, characters, booleans, `nil`, keywords, symbols
- vectors, maps, sets, quoted lists/data
- `if`, `if-not`, `when`, `when-not`, `cond`, `do`, `case`
- `and`, `or`, `not`
- `let` with vector/map destructuring, `:keys`, `:strs`, `:syms`, `:or`, `:as`,
  `&` rest bindings, and sequential rebinding
- `fn` / `fn*` (including named self-recursive functions)
- `loop` / `recur`
- anonymous function shorthand `#(...)` using `%`, `%1`, `%2`, ... (`%&` is
  not supported, see limitations)
- `->` and `->>`
- `try` / `catch` / `finally` (typed and untyped catch clauses)
- `throw`
- `doseq`, including nested bindings and destructuring
- `quote` / `'`
- atoms: `atom`, `deref` / `@`, `swap!`, `reset!`
- `set!` for locals and Dart fields

### Collections and core functions

A useful subset of `cljd.core` / `clojure.core`, including:

`+ - * / = not= < > <= >= inc dec mod rem quot abs count get get-in nth subs
assoc assoc-in dissoc update update-in merge conj into keys vals contains? find
first second last rest next seq vec reverse sort sort-by distinct flatten take
drop take-while drop-while concat partition some every? not-any? not-every?
range map mapv map-indexed filter remove reduce reduce-kv apply partial comp
juxt complement constantly identity min max list vector hash-map set str pr-str
print println pr prn keyword symbol name namespace atom deref reset! swap!
nil? some? true? false? number? integer? double? string? keyword? symbol? map?
vector? list? set? fn? coll? empty? zero? pos? neg? even? odd? boolean rand`

String helpers:

`str/join str/split str/upper-case str/lower-case str/trim str/triml str/trimr
str/capitalize str/blank? str/starts-with? str/ends-with? str/includes?
str/replace str/replace-first`

### Dart interop

- `(.method obj args...)` and `(. obj method args...)`
- `(.-field obj)`
- `(Class/member args...)`
- constructors: `(ClassName. args...)` and uppercase class calls

Calls to Clojure-level functions go through the runtime's `_rt_invoke`, so
functions, keywords, symbols, vectors, maps, and variadic helper objects can all
be called uniformly. Dart constructors and interop calls remain direct Dart
calls.

## Limitations

This is intentionally a subset. Known gaps:

- No macros, `defmacro`, syntax quote, or `&form`/`&env`.
- No multi-arity `defn`; use one arity.
- No variadic `fn` / `defn` parameters (`& rest` in a parameter vector).
  `doseq` and destructuring rest bindings are supported.
- No `for`, `lazy-seq`, protocols, records, types, or deftype.
- `loop` bindings must be plain symbols (no destructuring).
- No `..` chained interop.
- No ClojureDart Flutter DSL (`cljd.flutter`), so Flutter widget code is out of
  scope.
- `%&` in `#(...)` is rejected by the ClojureDart reader used here. Bare `%` is
  rewritten to `%1` by the CLI before reading; use `%1`, `%2`, ... explicitly
  when possible.
- Generated code assumes untyped `dynamic` values. It is meant to run, not to
  provide static Dart types.
- Division uses Dart semantics (`1 / 0` is `Infinity`); there is no
  `ArithmeticException` for division by zero.

## Project layout

```
cljd2dart                     wrapper that rebuilds and runs the tool
bin/cljd2dart.dart            Dart entry point (exports generated main)
src/cljd2dart/main.cljd       CLI: argument parsing, stdin/file input
src/cljd2dart/transpile.cljd  reader forms -> Dart source
src/cljd2dart/runtime_src.cljd embedded runtime string (generated)
runtime.dart                  editable standalone Dart runtime
scripts/embed_runtime.py      runtime.dart -> runtime_src.cljd
scripts/test.sh               end-to-end example tests
examples/*.cljd               sample inputs
examples/*.expected           expected stdout for the tests
```

### Runtime embedding

ClojureDart has no compile-time file include, so `runtime.dart` is embedded as a
string in `src/cljd2dart/runtime_src.cljd`. After editing `runtime.dart` run:

```sh
python3 scripts/embed_runtime.py
```

The wrapper does this automatically when `runtime.dart` is newer than the
generated file.

## How it works

1. `main.cljd` reads the source, normalizes bare `%` placeholders, and parses
   forms with `cljd.reader/read-stream`.
2. `transpile.cljd` walks the forms. Special forms and threading macros are
   expanded/emitted directly; ordinary calls are routed through the runtime.
3. A header with Dart imports and the embedded runtime is prepended, producing
   one standalone `.dart` file.
4. Dart's analyzer and runtime can then be used on the result.
