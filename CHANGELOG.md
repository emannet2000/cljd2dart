# Changelog

## 0.1.0

- Initial ClojureDart-to-Dart source transpiler written in ClojureDart.
- CLI with file, stdin, stdout, output-path, help, and version options.
- Runtime for collections, higher-order functions, strings, printing, equality,
  atoms, and variadic core functions.
- Example programs and end-to-end tests.
- `try`/`catch`/`finally`, nested `doseq`, and `#(...)` placeholder support.
